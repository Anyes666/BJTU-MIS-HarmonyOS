# BJTU MIS HarmonyOS

本项目的部分实现思路参考了 [wan300/bjtu_mis_Android](https://github.com/wan300/bjtu_mis_Android.git) 和 [HFDLYS/BJTUselfService](https://github.com/HFDLYS/BJTUselfService.git)。

一个面向北京交通大学学生的非官方 HarmonyOS 教学项目。项目尝试将课表、考试、成绩等常用教务信息整理为清晰的原生界面，并在用户完成学校官方登录后保存本地离线快照，减少重复打开网页查询的操作。

> [!IMPORTANT]
> 本项目由个人独立开发，仅用于学习、教学与技术交流，与北京交通大学及其信息化部门不存在隶属、合作、授权或背书关系。项目名称中的学校简称仅用于说明适用场景。

## 在自己的手机上使用

> [!NOTE]
> 本仓库仅提供源代码，不提供预编译或已签名的安装包。请自行构建，并使用自己的本地签名安装到设备。

### 自行构建（开发者）

1. 克隆本仓库，并使用 DevEco Studio 打开项目。
2. 在自己的电脑中配置本地调试/发布签名；**不要**提交证书、私钥、签名口令或本机的 `build-profile.json5` 改动。
3. 构建已签名 HAP，再通过 DevEco Studio 或 HDC 安装到已开启开发者调试的 HarmonyOS 手机。
4. 安装后按上述“登录并同步”流程使用。请仅查询本人有权访问的数据，并以学校官方系统显示为准。

### 常见情况

- **首次安装没有课表、考试或成绩**：先完成官方登录，再点击同步并等待结果；同步失败不会清除已经验证过的本地快照。
- **重新安装后需要重新同步**：卸载应用会删除应用本地缓存，这是正常现象；重新登录并同步即可恢复。
- **成绩或课表与官方页面不一致**：请先手动同步一次；涉及成绩认定、毕业审核等重要用途时，请以学校官方系统为准。

## 主要功能

- 默认展示当前学期周课表、今日课程与课程详情，并标注每节课的起止时间
- 考试安排、学期筛选与时间线
- 历年成绩、课程详情、累计学分加权平均成绩与四级制 GPA 本地计算
- 个人与培养信息、学业进度
- 学年校历与教学周
- 数据同步状态、变化记录与单模块重试
- 校园邮箱官方入口
- 经典默认与五套内置照片主题，支持预览、应用、重启恢复及跟随系统浅色/深色模式
- A/B 原子快照、损坏回退和离线查看

具体页面及字段以学校系统实际提供的信息为准。学校页面结构发生变化时，相应解析功能可能暂时不可用。

## 课表与个性化外观

周课表默认显示当前学期，左侧节次同时显示对应的起止时间。课程色块、卡片、按钮、导航栏和系统栏统一使用当前主题色板；正文通过受控遮罩或磨砂表面保证可读性。

设置页的“个性化外观”提供经典默认及五套内置照片主题。选择主题后可以先预览浅色或深色效果，只有点击“应用主题”才会保存；主题配置使用独立本地存储，不会随课程、考试或成绩数据清理而删除。本阶段不包含用户自定义照片上传。

内置主题图片仅作为界面演示素材。图片、角色或其他第三方视觉素材的权利仍归各自权利人所有；公开分发、二次使用或商用前，请自行确认授权，无法确认时应替换为具有明确许可的素材。

## 登录与数据更新

应用使用 ArkWeb 打开学校官方认证和教务页面。用户在官方页面中自行完成登录；应用业务代码不读取账号密码、验证码、Cookie、Session 或 Authorization，也不导出或上传这些信息。

登录状态由系统 Web 组件按照网站策略保存在本机，应用只请求 Web 组件持久化其本地 Cookie 存储，不提取 Cookie 内容。会话是否持续有效由学校认证系统决定，项目无法保证永久免登录。同步在应用内访问学校官方页面并解析必要的结构化结果，旧快照在同步失败时会保留。

## 隐私与安全

- 项目没有自建服务器、统计服务或云端数据库。
- 课表、考试、成绩等快照只保存在应用本地沙箱。
- 已关闭应用业务数据的系统备份恢复。
- 只允许访问代码白名单中的学校官方 HTTPS 主机。
- 不缓存头像、附件及不必要的身份字段。
- 日志不得记录成绩明细、邮件正文、联系人或认证信息。

更完整的说明请阅读 [PRIVACY.md](PRIVACY.md) 和 [SECURITY.md](SECURITY.md)。

## 技术结构

项目使用 ArkTS 与 ArkUI 开发，主要结构如下：

```text
entry/src/main/ets/
├─ pages/       原生页面与官方网页容器
├─ components/  课表等可复用组件
├─ common/      动态主题色板、注册表与通用配置
├─ parser/      官方页面结构化解析
├─ manager/     同步协调、主题状态与访问白名单
├─ model/       课表、考试、成绩等数据模型
└─ store/       本地版本化快照与回退
```

同步数据采用模块化提交。课表、考试或成绩中的单个模块失败时，已验证的旧数据不会被无条件清空；只有完整、可信的新快照才能确认删除事件。

## 开发环境

- DevEco Studio（支持 HarmonyOS SDK API 24）
- HarmonyOS 6.1.1，`targetSdkVersion 24`
- 最低兼容版本 `compatibleSdkVersion 19`
- Node.js 与 Hvigor 版本以 DevEco Studio 当前工程要求为准

首次导入后，请在 DevEco Studio 中安装依赖并配置你自己的本地调试签名。本仓库不包含任何开发者证书、私钥或签名口令。

### 构建

在 DevEco Studio 中选择 `entry` 模块执行 **Build Hap(s)/APP(s) > Build Hap(s)**。也可以使用项目配置对应的 Hvigor 命令构建主 HAP 与 ohosTest HAP。

当前源码在发布前完成了以下本地验证：

- 主 HAP 构建成功
- ohosTest HAP 构建成功
- 80 项测试通过
- HarmonyOS 模拟器安装、启动、五套主题深浅色核心页面及主题持久化检查通过

这些结果只代表该次本地环境，不构成对所有设备、所有账号或学校未来页面版本的兼容承诺。
