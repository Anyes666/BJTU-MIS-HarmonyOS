# BJTU MIS HarmonyOS

本项目的部分实现思路参考了 [wan300/bjtu_mis_Android](https://github.com/wan300/bjtu_mis_Android.git) 和 [HFDLYS/BJTUselfService](https://github.com/HFDLYS/BJTUselfService.git)。

一个面向北京交通大学学生的非官方 HarmonyOS 教学项目。项目尝试将课表、考试、成绩等常用教务信息整理为清晰的原生界面，并在用户完成学校官方登录后保存本地离线快照，减少重复打开网页查询的操作。

> [!IMPORTANT]
> 本项目由个人独立开发，仅用于学习、教学与技术交流，与北京交通大学及其信息化部门不存在隶属、合作、授权或背书关系。项目名称中的学校简称仅用于说明适用场景。

## 在自己的手机上使用

> [!NOTE]
> 本仓库仅提供源代码，不提供预编译或已签名的安装包。请自行构建，并使用自己的本地签名安装到设备。

### 先了解：不能直接在手机上编译

HarmonyOS 原生项目需要在 Windows 电脑的 DevEco Studio 中完成签名和构建；手机用于安装、运行和调试。下面的流程从下载源码开始，完成后可直接在自己的 HarmonyOS 手机上使用。

### 准备条件

1. 一台 Windows 电脑，并安装支持 HarmonyOS SDK API 24 的 DevEco Studio。
2. 一台 HarmonyOS 手机和可用的 USB 数据线。本项目仅声明支持手机设备，不支持平板、PC 或 Wearable 构建目标。
3. 手机和电脑可访问学校官方认证、教务和邮箱页面；首次同步需要联网。
4. 一个自己的华为开发者签名配置。调试签名即可安装到个人设备，不需要把证书或密码提供给本项目。

### 第 1 步：下载并打开源码

可任选一种方式获取代码：

```bash
git clone https://github.com/Anyes666/BJTU-MIS-HarmonyOS.git
cd BJTU-MIS-HarmonyOS
```

也可以在 GitHub 点击 **Code > Download ZIP**，解压后继续。打开 DevEco Studio，选择 **Open** 并选中项目根目录（包含 `oh-package.json5` 和 `entry` 文件夹的目录）。首次打开时等待依赖同步完成；如果 IDE 提示安装 SDK 或 Node.js/Hvigor 组件，按提示安装后重新同步工程。

### 第 2 步：配置自己的调试签名

在 DevEco Studio 的项目签名设置中，为 `entry` 模块创建或选择自己的 **Debug** 签名。不同版本的 IDE 菜单名称可能略有不同，通常在 **File > Project Structure > Signing Configs**；选择自动生成调试签名即可。

- 签名文件、私钥、证书和口令只保存在自己的电脑中。
- 不要提交或上传本机的 `build-profile.json5` 改动。
- 如果学校、公司或团队已有统一签名，请按其要求配置；不要与已安装的同包名应用混用不同签名。

签名配置完成后，确认 IDE 不再显示“未配置签名”或“找不到证书”错误。

### 第 3 步：连接手机

1. 在手机 **设置 > 关于本机** 连续点击版本号，开启开发者选项；不同系统版本的入口文字可能略有差异。
2. 在 **开发者选项** 中开启 USB 调试，使用数据线连接电脑。
3. 手机上出现“允许 USB 调试”提示时选择允许；如有“始终允许此电脑”选项，可一并勾选。
4. 回到 DevEco Studio，确认设备管理器出现手机名称且状态为在线。首次连接可能需要等待系统驱动安装完成。

没有真机时，也可在 DevEco Studio Device Manager 创建并启动一个手机模拟器，再执行后续构建与运行步骤。

### 第 4 步：构建并安装到手机

1. 在 DevEco Studio 顶部运行配置中选择 `entry` 模块和已连接的手机。
2. 选择 **Build Hap(s)/APP(s) > Build Hap(s)**，等待底部 Build 输出出现 `BUILD SUCCESSFUL`。
3. 点击运行按钮，或选择 **Run > Run 'entry'**。DevEco Studio 会安装已签名的 HAP 并启动应用。
4. 手机桌面出现应用后，按应用内提示打开学校官方登录页；完成本人账号登录后进入同步中心同步课表、考试和成绩。

若只想生成安装包而不立即运行，成功构建后的默认产物通常位于 `entry/build/default/outputs/default/entry-default-signed.hap`。仍建议优先通过 DevEco Studio 安装，以便直接查看设备和安装错误。

### 第 5 步：首次使用

首次安装不会自带个人课表、考试或成绩。请完成官方登录后点击同步并等待结果；同步失败不会清除已经验证过的本地快照。设置页可选择内置主题或导入自定义照片，照片和主题分析结果仅保存在本机。

### 常见问题

- **DevEco Studio 提示 SDK、Node.js 或 Hvigor 缺失**：在 IDE 的 SDK/工具链设置中安装项目要求的 HarmonyOS SDK API 24 组件，完成后执行同步工程，再重新构建。
- **Build 失败并提示未配置签名、证书不存在或口令错误**：回到项目签名设置，重新选择或生成自己的 Debug 签名；不要复制他人的证书、私钥或 `build-profile.json5`。
- **手机未显示、状态为 Offline 或一直等待设备**：拔插数据线，确认手机已开启 USB 调试并允许当前电脑；更换支持数据传输的线材或 USB 接口后，在 Device Manager 重新连接。
- **安装报 `9568332` / `install sign info inconsistent`**：设备上残留了同包名但签名不同的旧应用或保留数据。先关闭 DevEco Studio 的“Keep Application Data”，再卸载旧应用后重新运行；卸载会清除该应用本地数据，请先确认已同步的重要数据。
- **安装成功但首次打开闪退或停留在启动页**：在 DevEco Studio 的 Run/Log 窗口查看首条异常；确认构建产物来自当前 `entry` 模块，并重新安装一次。不要在不明来源的 HAP 上覆盖安装。
- **首次同步没有课表、考试或成绩**：确认已在官方页面完成本人账号登录并保持网络可用，然后在同步中心重试。学校页面改版、认证过期或网络限制都可能造成同步失败。
- **成绩或课表与官方页面不一致**：先手动同步一次；涉及成绩认定、毕业审核等重要用途时，请以学校官方系统为准。
- **自定义照片无法选择或主题没有保存**：确认系统相册选择器未被取消，图片不超过 50 MB 且像素不超过 5000 万；选择后需在预览页点击“应用此背景”。

## 主要功能

- 默认展示当前学期周课表、今日课程与课程详情，并标注每节课的起止时间
- 考试安排、学期筛选与时间线
- 历年成绩、课程详情、累计学分加权平均成绩与四级制 GPA 本地计算
- 个人与培养信息、学业进度
- 学年校历与教学周
- 数据同步状态、变化记录与单模块重试
- 校园邮箱官方入口
- 经典默认、五套内置主题与自定义照片背景，支持预览、应用、重启恢复及跟随系统浅色/深色模式
- A/B 原子快照、损坏回退和离线查看

具体页面及字段以学校系统实际提供的信息为准。学校页面结构发生变化时，相应解析功能可能暂时不可用。

## 课表与个性化外观

周课表默认显示当前学期，左侧节次同时显示对应的起止时间。课程色块、卡片、按钮、导航栏和系统栏统一使用当前主题色板；正文通过受控遮罩或磨砂表面保证可读性。

设置页的“个性化外观”提供经典默认、五套内置照片主题和“自定义照片”。自定义照片通过系统相册 Picker 单选导入，不申请全相册读取权限；图片会在本机等比缩放并按 Cover 规则铺满背景，用户可单指拖动、双指缩放调整取景。应用在本机提取照片主色，为浅色和深色模式生成按钮、卡片、导航及课表色板，照片与分析结果均不上传。

选择或更换照片后只进入预览，点击“应用此背景”才会保存。源图片限制为 50 MB、5000 万像素以内，规范化副本最长边不超过 2160 px；主题配置和私有图片使用独立本地存储，不会随课程、考试或成绩数据清理而删除。处理失败或取消时保留原主题。

内置主题图片仅作为界面演示素材。图片、角色或其他第三方视觉素材的权利仍归各自权利人所有；公开分发、二次使用或商用前，请自行确认授权，无法确认时应替换为具有明确许可的素材。

## 登录与数据更新

应用使用 ArkWeb 打开学校官方认证和教务页面。用户在官方页面中自行完成登录；应用业务代码不读取账号密码、验证码、Cookie、Session 或 Authorization，也不导出或上传这些信息。

登录状态由系统 Web 组件按照网站策略保存在本机，应用只请求 Web 组件持久化其本地 Cookie 存储，不提取 Cookie 内容。会话是否持续有效由学校认证系统决定，项目无法保证永久免登录。同步在应用内访问学校官方页面并解析必要的结构化结果，旧快照在同步失败时会保留。

## 隐私与安全

- 项目没有自建服务器、统计服务或云端数据库。
- 课表、考试、成绩等快照只保存在应用本地沙箱。
- 已关闭应用业务数据的系统备份恢复。
- 只允许访问代码白名单中的学校官方 HTTPS 主机。
- 不缓存头像、附件及不必要的身份字段。
- 日志不得记录成绩明细、邮件正文、联系人或认证信息。

更完整的说明请阅读 [PRIVACY.md](PRIVACY.md) 和 [SECURITY.md](SECURITY.md)。

## 技术结构

项目使用 ArkTS 与 ArkUI 开发，主要结构如下：

```text
entry/src/main/ets/
├─ pages/       原生页面与官方网页容器
├─ components/  课表等可复用组件
├─ common/      动态主题色板、注册表与通用配置
├─ parser/      官方页面结构化解析
├─ manager/     同步协调、主题状态与访问白名单
├─ model/       课表、考试、成绩等数据模型
└─ store/       本地版本化快照与回退
```

同步数据采用模块化提交。课表、考试或成绩中的单个模块失败时，已验证的旧数据不会被无条件清空；只有完整、可信的新快照才能确认删除事件。
