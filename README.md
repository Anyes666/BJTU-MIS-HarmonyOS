# BJTU MIS HarmonyOS

一个面向北京交通大学学生的非官方 HarmonyOS 教学项目。项目尝试将课表、考试、成绩等常用教务信息整理为清晰的原生界面，并在用户完成学校官方登录后保存本地离线快照，减少重复打开网页查询的操作。

> [!IMPORTANT]
> 本项目由个人独立开发，仅用于学习、教学与技术交流，与北京交通大学及其信息化部门不存在隶属、合作、授权或背书关系。项目名称中的学校简称仅用于说明适用场景。

## 主要功能

- 当前学期周课表、今日课程与课程详情
- 考试安排、学期筛选与时间线
- 历年成绩、课程详情、累计学分加权平均成绩与四级制 GPA 本地计算
- 个人与培养信息、学业进度
- 学年校历与教学周
- 数据同步状态、变化记录与单模块重试
- 校园邮箱官方入口
- 跟随系统的浅色/深色模式
- A/B 原子快照、损坏回退和离线查看

具体页面及字段以学校系统实际提供的信息为准。学校页面结构发生变化时，相应解析功能可能暂时不可用。

## 登录与数据更新

应用使用 ArkWeb 打开学校官方认证和教务页面。用户在官方页面中自行完成登录；应用业务代码不读取账号密码、验证码、Cookie、Session 或 Authorization，也不导出或上传这些信息。

登录状态由系统 Web 组件按照网站策略保存在本机，应用只请求 Web 组件持久化其本地 Cookie 存储，不提取 Cookie 内容。会话是否持续有效由学校认证系统决定，项目无法保证永久免登录。同步在应用内访问学校官方页面并解析必要的结构化结果，旧快照在同步失败时会保留。

## 隐私与安全

- 项目没有自建服务器、统计服务或云端数据库。
- 课表、考试、成绩等快照只保存在应用本地沙箱。
- 已关闭应用业务数据的系统备份恢复。
- 只允许访问代码白名单中的学校官方 HTTPS 主机。
- 不缓存头像、附件及不必要的身份字段。
- 日志不得记录成绩明细、邮件正文、联系人或认证信息。

更完整的说明请阅读 [PRIVACY.md](PRIVACY.md) 和 [SECURITY.md](SECURITY.md)。

## 技术结构

项目使用 ArkTS 与 ArkUI 开发，主要结构如下：

```text
entry/src/main/ets/
├─ pages/       原生页面与官方网页容器
├─ components/  课表等可复用组件
├─ parser/      官方页面结构化解析
├─ manager/     同步协调与访问白名单
├─ model/       课表、考试、成绩等数据模型
└─ store/       本地版本化快照与回退
```

同步数据采用模块化提交。课表、考试或成绩中的单个模块失败时，已验证的旧数据不会被无条件清空；只有完整、可信的新快照才能确认删除事件。

## 开发环境

- DevEco Studio（支持 HarmonyOS SDK API 24）
- HarmonyOS 6.1.1，`targetSdkVersion 24`
- 最低兼容版本 `compatibleSdkVersion 19`
- Node.js 与 Hvigor 版本以 DevEco Studio 当前工程要求为准

首次导入后，请在 DevEco Studio 中安装依赖并配置你自己的本地调试签名。本仓库不包含任何开发者证书、私钥或签名口令。

### 构建

在 DevEco Studio 中选择 `entry` 模块执行 **Build Hap(s)/APP(s) > Build Hap(s)**。也可以使用项目配置对应的 Hvigor 命令构建主 HAP 与 ohosTest HAP。

当前源码在发布前完成了以下本地验证：

- 主 HAP 构建成功
- ohosTest HAP 构建成功
- 71 项测试通过
- HarmonyOS 模拟器安装、启动及深浅色页面检查通过

这些结果只代表该次本地环境，不构成对所有设备、所有账号或学校未来页面版本的兼容承诺。

## 使用边界

使用本项目时，请遵守法律法规、学校管理规定和相关网站的使用条款，并仅访问你本人有权查看的数据。禁止将本项目用于：

- 绕过身份认证、验证码或网站访问控制
- 获取、传播或处理他人的个人信息和教务数据
- 高频请求、压力测试、批量爬取或干扰学校系统
- 抢课、自动评教、作弊或其他违反校规的自动化行为
- 未经许可的商业服务或产品背书

本项目按“现状”提供，不保证数据完整性、实时性或适用于成绩认定、毕业审核、评奖评优等正式用途。重要信息应以学校官方系统和通知为准。
